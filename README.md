# vwl-ai-chat

Headless on-device chat for Vanduo Web Labs. LiteRT, WebLLM, and Transformers.js, with local guardrails and CSP-safe markdown.

Not published. [Labs](https://github.com/nostromo-618/labs) consumes it as a sibling (`link:../vwl-ai-chat`).

Default model: Gemma 4 E2B LiteRT (`gemma-4-E2B-it-web`). Needs WebGPU.

```bash
pnpm install && pnpm build
```

Spec: [openspec/](./openspec/).
